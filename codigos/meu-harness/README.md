# meu-harness

O harness de usuário construído ao longo do curso Harness Engineering. Cada pasta tem
dono, e no começo do curso todas estão vazias:

```
meu-harness/
├── AGENTS.global.md       fonte das instruções globais        (cap. 2)
├── templates/             modelos de instruções e de projeto  (caps. 2 e 3)
├── skills/                procedimentos sob demanda           (cap. 4)
├── hooks/                 verificações automáticas            (cap. 5)
├── settings-usuario.json  permissões e hooks do usuário       (cap. 5)
├── agents/                subagentes                          (caps. 6 e 7)
├── mcp/                   servidor MCP próprio                (cap. 7)
├── .claude-plugin/        manifesto do plugin                 (cap. 8)
└── diario-de-falhas.md    o que deu errado, e onde foi resolvido (todos)
```
